# Code of Conduct

## Our Pledge

We pledge to make participation in this project a respectful, harassment-free experience for everyone.

## Expected Behavior

- Be kind and specific.
- Assume good intent while staying accountable for impact.
- Keep feedback focused on the work.
- Respect boundaries and privacy.

## Unacceptable Behavior

- Harassment, threats, or discriminatory language.
- Publishing private information without consent.
- Sustained disruption of project spaces.

## Enforcement

Project maintainers may remove comments, issues, pull requests, or contributors that violate this code of conduct.

Report concerns to baditaflorin@gmail.com.
